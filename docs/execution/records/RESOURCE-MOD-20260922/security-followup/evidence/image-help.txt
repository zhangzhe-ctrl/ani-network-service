Usage of /ani-resource-service:
  -base-connectivity string
    	admin mode: plan, status, resume, pause, dispatch, rollout, enable-new, disable-new, activate-legacy
  -base-interval duration
    	shared minimum admission interval (100ms..1h), fixed at planning (default 1s)
  -base-max int
    	maximum candidates processed by dispatch (1..10000); accepted operations continue on service workers (default 1)
  -base-pool string
    	Intranet pool ID for a new plan; empty freezes the current default
  -base-reviewed-sha256 string
    	exact reviewed plan SHA-256 required for resume
  -base-run string
    	stable reviewed backfill run UUID
  -conf string
    	config path, for example -conf configs/config.yaml (default "configs")
  -migrate
    	apply Network migrations using explicit owner environment
  -node-facts
    	run the separately authorized read-only node facts collector
