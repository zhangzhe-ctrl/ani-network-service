# 本 run 采样计数偏差

两张执行前冻结的脚本均固定每来源/目标 6 次，没有失败后追加请求。
但 isolation-smoke 的 Tenant A 正向对照与 live-smoke 的 pod-cross-node 指向相同
Pod 地址/端口，导致每版本存在 12 次重复正向控制请求：

- isolation：24 个租户内成功预期请求、48 个跨租户拒绝预期请求。
- live：12 个 Pod 正向请求、24 个 Intranet 请求、12 个私网 LB 请求。
- 实际每版本总数 120；去重后的来源/目标矩阵为 108，其中上述 Pod 对为 12 次而非 6 次。

这是本次验收驱动的矩阵设计偏差，严格计数条件记 fail；不删除额外请求、不选择更好响应，
不追加重测，不将两个矩阵分别固定 6 次冒充每个实际来源/目标总计 6 次。
已取得的有界功能观测与“严格采样计数验收”分开记录，完整 R4 仍未通过。
未来具备完整 Public 前置时，需要先消除这项矩阵重叠，再冻结独立验收 run；
本 run 的全部原始结果保留，不能被新结果覆盖。

已提供 [修正驱动](live-smoke-unique.py)及[源码对照](sampling-correction.json)：
普通 Pod 通信复用隔离矩阵已有的 24 次正向控制，独立 live 矩阵缩为 36 次，
合计每版本 108 次且不重叠。本 run 未执行修正驱动；原始执行脚本及全部结果不改写。
